# sitskaggle

<!-- badges: start -->

<!-- badges: end -->

The goal of `sitskaggle` is to bundle SITS R package into kaggle’s
environment.

## Installation

You can install the development version of sitskaggle like so:

``` r
devtools::install_github("lipeverse/sitskaggle")
```

## Example

`sitskaggle` has only two functions: `install()` and `bundle()`. As the
names suggest, they **install** and **bundle** packages into kaggle.

``` r
library(sitskaggle)
sitskaggle::install()
```
